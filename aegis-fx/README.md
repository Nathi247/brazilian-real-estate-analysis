# AEGIS-FX

Planning documents for **AEGIS-FX**, a human-in-the-loop Forex decision-support system (MT5 + Python, EURUSD first, Telegram alerts, manual execution, no auto-execution).

| Document | What it is |
|---|---|
| [`PLAN.md`](PLAN.md) | **V4 plan.** Amends the V3 master build spec: design decisions, architecture, the strategy to test first, data plan, risk and execution, the LLM's role, validation protocol, staged roadmap with go/no-go gates, and what happens to each of the 30 proposed additions. Includes 9 flow charts (Mermaid). |
| [`REVIEW.md`](REVIEW.md) | **Evidence.** A five-lens adversarial review of V3 + the 30 additions: findings with numbers, fact checks, and limitations. |

No code is in this folder yet. The next step is Stage 0 (pre-registration), then Stages 1–2 (data foundation and research backtester). See `PLAN.md` §15–§16.

Nothing here claims the system is profitable, accurate, low-risk or production-ready. Those claims require the evidence described in `PLAN.md` §10.
